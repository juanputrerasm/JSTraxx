JSTraxx is a web implementation of Traxx, the classic Monster Truck Madness 2 track editor. Its editing rules, file output and help pages are ported from the Traxx source code.

## Where it comes from

| Version | Authors |
| --- | --- |
| Traxx (1997) | Copyright (c) 1997 SoftParts |
| Traxx 1.5 (2005) | Copyright (c) 2005 Richard Borchard III |
| Traxx 1.6 GL update | Juan Pablo Utreras "Kmaster" |
| Traxx 1.6 CP3 updates | Fila |
| JSTraxx | Juan Pablo Utreras "Kmaster" |

JSTraxx is built with [OpenPhotex](https://github.com/juanputrerasm/OpenPhotex) (TRI file formats) and takes its model rendering from [JSTrackViewer](https://github.com/juanputrerasm/JSTrackViewer). Both are separate projects under the Apache License 2.0; the copy of OpenPhotex in `src/vendor/openphotex` keeps that license.
