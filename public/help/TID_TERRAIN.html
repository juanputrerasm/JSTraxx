Terrain Editing.

Enter Terrain Edit mode using the first button in the Editmode Toolbar.

As you move the mouse across the world suface, a yellow grid appears to indicate the pending edit operation. The grid indicates how the terrain will change when the operation is applied. To apply the operation, just click the left mouse button or hit <spacebar>.

In some cases you may prefer to use the Wireframe option to get a clearer view of how the terrain looks. Note that the Wireframe check button has three states - the third displays the textures with the wireframe overlaid.

There are 8 options for you to specify the size/shape of the editing operation, which are selected from the toolbar in the bottom-right of the display:

Platform - this is the default operation, and indicates that a rectangular area will be raised or lowered by a fixed amount.

Hill - a symmetrical bell-shaped hill will be added to the terrain. The height of the peak can be varied, and the shape is stretched depending on the grid width and height.

Ramp - a slope is added to the terrain. Zero is added at one edge, and the height of the other can be varied.

Mound - similar to Hill, but in one dimension.

Random noise - used for adding bumpiness to the surface of variable amplitude.

Smooth - sets each point in the grid to the mean of surrounding values, having the effect of smoothing bumps and transitions.

Plane - sets the terrain to an absolute value (ie not additive like the others). Useful for defining flat areas such as lakes, roadways etc.

Direct keyboard - allows individual terrain points to be modified directly using the keyboard. The S/X keys will modify the terrain in real-time at the point where the mouse is currently located.

In all but the last two cases, the operation is additive - ie the function is added to the existing terrain. Note that the yellow grid shows how the terrain will look when the operation is performed.

You can specify positive or negative values in the Altitude box. Specifying a negative value with the Mound function, for example, will create a cut or ditch feature.

Use the S and X keys (adjacent to A and Z) or [ and ] to modify the Altitude value while editing. S increases it, X decreases it. You can even move the editing location around with the mouse while you change this to see how things will look.

Altitude values are overlaid on the display, showing what the current altitude is at the edit center-point (grey) and what it will be after the operation in white. Note: in direct keyboard mode, only the current altitude is displayed (which can be useful just for looking around).

Note that the mouse defines the location where the operation will apply based on where you are pointing on the surface of the existing terrain. A white line is drawn from this point up (or down) to the corresponding point on the yellow grid so you can see whats happening more easily. This also aids in visualising changes in the amplitude value (which is represented directly by the length of the white line).

The Orientation control is useful for changing the direction of Ramps and Mounds, and for applying non-square operations in any orientation. The <tab> key can be used to cycle through the 8 orientation settings (separated by 45 degrees).

The Curvature control changes the roundness or sharpness of the Hill, Ramp, Mound and Random noise tools. A high curvature setting gives more sharply-pointed features. The +/- keys can be used to change the curvature value.

The Undo option undoes the last function applied.

tip: Right-click and select Copy/Paste Terrain Bitmap and you can use any graphics program to edit the terrain.

tip: You can load the terrain RAW file from an existing tracked track into a graphics program (as an 8-bit, grey-scale image) and paste it into Traxx.

tip: Use the Special/Random Terrain option to generate an initial terrain with hills and valleys. Play with the sliders until you see something you like (see Special Functions).

Areas of terrain can be copied and pasted by right-clicking at the center of the area you want to copy. Select Copy Area from the menu and this will copy the area covered by the (yellow) terrain grid.

tip: Use the Raise/Platform tool (first one) with an altitude of 0 (zero), so you can easily see the covered area that you are going to copy.
