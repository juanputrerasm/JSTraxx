Moving Around

Moving around the 3D world.

· Up/Down  - Move forwards/back.

· Shift  - Turbo.

· Left/Right  - Change view orientation angle left/right.

· PgUp/PgDn - Change view elevation angle up/down.

· Numpad 5  - Set view elevation to straight-ahead (parallel to surface).

· A/Z   - Move vertical viewpoint location up/down.

· S/X  and [ ]  - Increase/decrease terrain altitude; raise/lower ground box.

· S/X   - Raise/lower scenery object 1 unit.

· S/X+Shift  - Raise/lower scenery object 5 units.

· S/X+Ctrl+Shift - Raise/lower scenery object 0.1 unit.

· D/C  - Move scenery object east/west 1 unit.

· D/C+Shift  - Move scenery object east/west 10 units.

· F/V   - Move scenery object north/south 1 unit.

· F/V+Shift  - Move scenery object north/south 10 units.

· F/V +Ctrl+Shift - Move scenery object north/south 100 units.

· G/B+Shift  - Tilt scenery object east/west 0.1º.

· G/B+Ctrl+Shift - Tilt scenery object east/west 0.01º.

· H/N  - Tilt scenery object north/south 1º.

· H/N+Shift  - Tilt scenery object north/south 0.1º.

· H/N+Ctrl+Shift - Tilt scenery object north/south 0.01º.

· 1/2   - Increase/decrease object box X dimension by 1 foot.

· 1/2+Shift  - Increase/decrease object box X dimension by 10 feet.

· 3/4   - Increase/decrease object box Y dimension by 1 foot.

· 3/4+Shift  - Increase/decrease object box Y dimension by 10 feet.

· 3/4+Shift+Ctrl - Increase/decrease object box Y dimension by 25 feet.

· <,/.>  - "Strafe" left/right.

Moving forward and back is done using the Up/Down arrow keys. Hold down the <shift> key while moving to go faster. Note that you can use F4 to lock current view height relative to the ground while moving around. You can use this for a pseudo-test-drive around your track.

The Left/Right arrow keys change the orientation angle (think of it as steering).

PgUp and PgDn change the view elevation angle - PgDn points the view downward, PgUp points the view upward. The central numpad key (5) sets the elevation angle to horizontal - useful for getting truck's-eye-view of terrain.

Changing your vertical position relative to the world surface is done using the A and Z keys - A to go up, Z to go down.

Just take a few seconds to work with these controls, and it soon becomes intuitive.

You can use any of these keys in any combination at a time - for example, to rotate the viewing angle while dropping down to ground level hold down the Right arrow and Z.

It is possible to go below the world surface (can be useful for looking at groundbox undersides). This also means you can go through hills etc.

By double-clicking on the small map display you can immediately jump to any location on the track. The map displays the start points of each (if any) of the main course segments in the track, so you have an idea where things are. The green dot indicates the start position of the first course segment (#0), so you can see approximately where the start line is.

Your current view-point location coordinates are show at the bottom-right of the Traxx window. The X/Y values range from 0->255, representing the grid square you are currently over. The Z value may exceed 255 because the program allows you to view the track from higher up than the extent of the track itself.

Note that X/Y coordinates for scenery objects, truck positions etc range from 0->16383 because each grid square is 64 pixels wide and these items are located on that coordinate basis.
