Program Setup

Program Setup.

The Traxx installation comprises the executable (Traxx.exe) and this help file. You can begin working on tracks right away by running the program, but you will need to locate and/or build texture and models databases.....

IMPORTANT!

You may need to setup the art and models folder locations so the program knows where to find the texture maps and bin model files - especially if you want to use the folders already installed on your system for tracked. To do this, select View/Options from the main program menu and click the folders tab.

You can re-use tracked folders, or (if you don't have tracked, or want to start fresh) use the default locations. In the latter case, you will need to build texture and model databases. This can be done in two ways:

· Load (View) existing track POD files and select Edit/Extract Models and Art from the main menu, or

· Copy .BIN files manually into the Models folder, and .ACT and .RAW files into the Art folder.

The first option is preferred. When you have files in these folders, you will be able to load textures and models from the Textures and Models boxes (available from the View menu).

When you specify folder locations that don't exist yet, they will be created for you (after confirmation).

Saving Files.

When creating tracks, you can save the track files anywhere - by default they will be placed in the Traxx installation folder, but you may want to create a sub-directory to keep them in. These Traxx files are quite small - they are compressed and much smaller than POD files. Unlike tracked, neither the Traxx program nor the folder where you store your track files need to be in your MTM folder.

You can use the Auto-Save feature to have Traxx automatically save your file every few minutes (View/Options/Auto-Save). You might want to use the "Use Special File" option, which will save your work periodically, but not overwrite the original - that way you won't risk losing any work, and you can still go back to the original if you decide not to keep the changes you have made. In this case, the auto file is saved into your Traxx install folder (eg C:\ProgramFiles\Traxx).

When your track is ready to go and you make the POD file, you will need to save it to your MTM folder (or wherever you keep your POD files if you use PODX).

It is not necessary to re-mount the POD file into MTM when you re-write it, of course... you only need to mount it with PODX (or podman) once when it is first created.
