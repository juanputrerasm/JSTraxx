Program Options

Program Options and Settings.

Adjusting the 3D Display.

The Gamma slider just below the map allows you to alter the brightness of the display to compensate for the characteristics of your monitor. Raise the value if the image appears too dark.

The Display Grid Size slider determines the dimensions of the square portion of the world grid which is displayed. Setting this to a lower value will improve the speed with which the image is drawn, but reduce the range of terrain that you can see at any one time. If you have a fast computer (233 MHz or more) you can probably set this at - or close to - the maximum size.

The Wire Frame button has three states, which allow you to cycle through displaying the terrain normally, as wire-frame, or normally with a wireframe overlay. The wireframe display is often useful for visualising the shape of the terrain, especially in areas which have similar textures applied.

Other miscellaneous settings.

A number of less frequently used options are available via the Options item in the View menu.

· View/Options/General

Polygon Render Quality can be increased to lessen the distortion in the display, which may be evident especially when you are close-up to objects of the terrain. Adjusting this setting will have some impact on the speed with which the display is drawn. The default setting is "LO". This setting has no effect on the terrain display if the wireframe option is set.

The three "Always Show..." buttons can be set to make the applicable items be displayed when you are in other editing modes. By default, course segments are only displayed when you are in Course Edit mode, and so on.

The water overlay grid can be switched on/off using the "Show Water" button.

The backdrop display can be switched on/off using the "Show Backdrop" button (note that the backdrop is never shown in wireframe mode).

Function keys F5 thru F9 are shortcuts to these options.

The Display Resolution settings can be used to increase/decrease the size of the main display area. If your display is running at a low resolution (ie 640x480 or 800x600) you might prefer 512x384. The higher settings greatly increase the scope of the display for those running on higher resolution monitors, but the speed of the display may vary proportionately (depending on the speed of your machine).

A set of check boxes is provided which allow you to turn on and off elements of the track. Course segments will always be displayed in Course Editing mode, ground-boxes will always be displayed in Groundbox mode etc, but it may also be useful to have the course segments diaplayed while locating checkpoint objects and so-on...

Note that all of these options have function-key shortcuts so you can switch them without having to come into View/Options.

The "Show water" option applies to MTM2 only.

· View/Options/Folders

Use these settings to determine where your textures and models are located. You can have multiple Art/Models folders if you want - this can make it easier when you are browsing to find a particular texture, if the folder only contains a smaller set (rather than having to go through the whole set). However, note that the program only uses ONE set of folders at a time - so you can't have data from more than one folder pair in one track!

Use multiple folders with care!

· View/Options/Auto-Save

If you check the "Save Every..." box, Traxx will save your file at the specified interval of minutes.

You might want to use the "Use special file" option, which avoids overwriting the original so that you can always go back to that should you want to disregard any changes you made. In this case the file is saved into your Traxx installation folder (eg C:\ProgramFiles\Traxx).

· View/Options/Colors

This allows you to change the colors used to display certain elements in the program. For example, you might want to display black altitude numbers in the terrain editor if you are using snow-covered textures.
