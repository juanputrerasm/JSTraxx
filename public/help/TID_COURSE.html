Course Editing.

Enter Course Edit mode using the third button in the Editmode Toolbar.

There are 5 courses in MTM tracks: one main/primary course and 4 "extended" courses. The former is mandatory, and the latter are used to define how computer trucks run the course in MTM (you should normally define at least the first two of these).

Note: MTM2 trucks always follow extended course #2.

Courses are defined by a series of segments. The first course segment of the primary course is inserted by right-clicking on the terrain and selecting Insert Segment from the context menu. As the mouse moves over the ends of a segment you will see those ends highlighted - when this occurs, you can click and drag that segment end to where you want it to be on the terrain.

Once a first segment has been inserted, additional ones can only be added by right-clicking on the end of an existing segment. This allows you to insert segments in sequence before or after the currently highlighted one. If you insert a segment using the start of an existing one, it will be placed in sequence before it, if you insert using the end it will be placed after.

The sequence of course segments is indicated by numbers that are always displayed at the start end of segments (so you can easily see which direction the course is running). Segment start-points are highlighted in green when selected, end-points are highlighted in red.

Normally you would completely define the primary course before doing the extended courses. There is a Generate from Main option in the context menu which makes a duplicate of the main course with small random differences - this is much quicker and easier than defining the extended course segments manually! You can always edit the main or extended course segments at any time. Mouse-editing extended courses is identical to editing the main course, except the course segments are displayed in magenta (so you can tell what's what).

By default, only the course being edited will be displayed, but there is an Always show Main option that keeps the main course displayed while you are editing the extended courses.

The eight triangles on the display represent the truck starting positions. You can move these around by clicking and dragging with the mouse. To change their orientation, right-click on them and select Properties from the context menu - there you can set the orientation angle (which will be reflected in the direction that the triangle points on the display).

It is recommended that you place course-segment 0 (zero - the first one) so that it runs across the start/finish line of your track, and that you arrange all 8 trucks to be over this segment (oriented at least roughly parallel to it).
