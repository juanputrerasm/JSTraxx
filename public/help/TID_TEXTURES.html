Texture Editing

Texture Editing.

Enter Texture Edit mode using the second button in the Editmode Toolbar.

[Note: this section applies to terrain surface texture editing - to work with ground-box textures, you do not need to switch to this mode (stay in ground-box mode), but the same methods as described here apply.]

As you move the mouse across the world suface, a red box outlines the world grid squares. Select a square by clicking. You can select a rectangular block of squares by selecting one normally, then holding down <shift> and selecting another.

When a selection is made, it will be outlined in magenta. Note that texture editing is best performed with a near-vertical view angle, so you can see the selection more clearly.

To Rotate or Mirror the textures currently selected, use the Right mouse button and select those options from the context menu. These options process each selected texture square independently - see below for options that operate on areas. You can also use M and R to mirror/rotate areas of textures, and the same with <Ctrl> depressed will mirror/rotate textures individually.

To apply a new texture to the selected squares, you need to select textures from the Textures Box, or right-click on a terrain square with the texture you want and click Select from the popup menu.

The Textures Box shows all the textures currently loaded into the track. Activate the Textures Box using View/Textures (see also Textures Box). You can select one at a time for application by clicking on it - the currently selected texture is outlined in red.

The texture is applied to the selected area of the surface using the Apply button, or just by clicking on the surface if you are in using Paint Mode.

To do this, you must first select the required texture, and click the Paint Mode check-box in the toolbar at the right of the main display. Now when you move the mouse around the terrain you will see that the magenta selection rectangle follows the mouse around. You apply the currently selected texture to all squares within the purple box simply by clicking with the mouse.

The size of the area (ie number of terrain grid squares) that the texture will be applied to is changed using the Width and Height boxes adjacent to the Paint Mode check box.

Working with areas.

Rectangular blocks of textures can be copied and pasted from one location to another using the Copy/Paste Area options in the right-click menu. This feature is probably most easily used in Paint Mode with a square area, but the area does not have to be square.

Rotate Area and Mirror Area (also R and M keys) process the current selection as a unified block. This is especially useful for copying a composite area defining a race-track corner section, then pasting and re-arranging to quickly make the other corners on the track. In this way you only need to manually "build" the corner once.

Texture Patterns.

You can save rectangular areas of textures as "patterns", and then reload later when building another track. This option is also useful as an additional "copy buffer", whereby you can save an area as a pattern and then paste it from there at other locations in the track.

Primarily intended for road corners and other common patterns, the facility can be used to store any area up to 16x16 grid squares.

The Patterns box is accessed via View/Patterns in the main menu (or via the right-click menu in Texture editing mode).

Patterns are added to the Patterns file by copying them from the track (as described above) and then pasting them into the Patterns box. Similarly, you copy patterns from the Patterns box and paste into the track.

 As soon as you paste an area in, the file is saved. You can have any number of patterns files on your computer - use the FileOpen button to select from another existing file, or create a new one.

In order to place a pattern into your track, scroll to the pattern you want, then click the Copy button in the Patterns Box and then paste onto the terrain in the usual way (described above). Note that when you "Copy" a pattern, the width and height of the purple outline box on the terrain are adjusted automatically (Paint Mode only).

This facility can be used to copy texture patterns from existing track POD files! Use ViewPODFile and then go to Texture editing mode and you can copy areas into your Patterns file(s).
