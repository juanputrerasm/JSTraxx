Texture Box

Textures Box.

Access the Textures Box using View/Textures in the main menu (or from the right-click menu in Texture editing mode).

The textures shown in this box are used for the terrain and ground-boxes (textures used by BIN models are handled automatically and separately by Traxx).

The main display shows all the textures currently included in the track. Textures are loaded using the Load >> button, which shows all the textures in your Art folder. You can scroll through the pages of textures using the buttons in the bottom-right, and then load them by double clicking on them (or use the Load Page button.

When you have activated the Load >> section, you can apply a filter to list only those with particular names. For example, type "C8DR*" in the small "Files:" box at the top and hit Refresh - you will then see a listing of just the Crazy98 track textures (assuming you have extracted those, of course).

Type / Grip depth.

Each texture can be assigned a Type, which will affect the way that the trucks handle on those squares, the skidding sound, and the color of dirt kick-up.

Grip depth determines how far the truck's tire treads sink into the terrain, which affects the trucks handling. Typically grass textures will be set to 2->4, mud/sand to 3->5, cement to 0->1. If you set the type to "Ice" with a grip-depth of 0 you go spinning almost uncontrollably. "Water" type grip depths are often in the range 20->40 to allow trucks to go at least partially underwater.

Note: "Rocks" and "Mud" are very slippery!

tip: To set many textures quickly, click on the Type or Grip Depth control, so its highlighted. Then click on the textures on-by-one and use the up/down arrow keys to change the setting for each.

Custom Textures.

Custom textures are created simply by pasting images in using the Paste Texture and Paste Composite buttons. For either option, you can Copy an image from any graphics program - the image must be in 8-bit (256 color) format. In the former case, the image must be either 64x64 or 256x256 pixels in size.

The Paste Composite option allows you to extract a grid of many textures automatically from a single over-size image. See Cut Textures from Bitmap.

tip: If you use custom textures, you may want to create an optimized color palette for your track so that they are displayed correctly (the palettes from the stock tracks may not include the colors that your textures need). See Special Functions.

You can use the Copy button (or right-click/Copy) to copy a texture for pasting into a graphics program for editing. When you do this, the texture is copied out with its original palette (ACT) so it will appear correctly (previous versions of Traxx copied it out with the track's master palette).

Animated Textures.

In order to animate a texture, select it and then hold <Ctrl> while clicking on the other textures in the animation sequence, in order. As you do this, a number will appear indicating the texture's place in the sequence. Note that the texture will not be animated on the main Traxx display.

Having setup a sequence of textures, you can then click the Animate button to see a preview and adjust the frame rate. The Period is the amount of time each frame is shown, in milliseconds. The default is 250, which is 4 frames per second. The lower the number, the faster the animation will run.

Purging Textures.

To minimize the size of your track's POD file, the Purge Unused Textures option will remove all the textures that you have loaded but are not actually applied to any terrain location or ground-box. Before proceeding, it will pop up a box indicating how many (if any) textures are unused - so you can use it just to see...

This is a useful option to use prior to final completion of the track, especially if its going to be downloaded by people on the 'net.

Texture Rename/Delete.

You can right-click on textures in the Load >> section to display a popup menu with Rename and Delete options. These funtions operate on the actual texture files, and should be used with care! Traxx won't allow you to use these on textures that you currently have loaded in the track you are working on.

Note that you should click the "Refresh" button to update the display after deleting or renaming textures, since they may still be shown if you scroll away and return to that page (due to the cacheing mechanism used), even though the files aren't there anymore.
