Introduction

Traxx creates tracks for MTM1 and MTM2.

The program provides an unrestricted 3D environment in which the terrain map, texture-mapping, course definitions and scenery objects can be edited, and includes all the necessary facilities for specifying the other components of MTM tracks.

For each track you create, all working data is maintained in a single, compressed file (proprietary format, with extension ".txx"). These files are typically less than 1/10th the size of POD files. When a track is complete - or if you want to test a track during its development - the POD file is generated with a single button click from within the program.

Traxx can also be used to view (but not edit) existing MTM track PODs.

Texture map art (.raw) and models (.bin) are loaded from external folders, which can be the existing tracked folders if you have them already. Preview panes are provided to ease the process of loading texture map files.

An Undo feature is included for terrain and texture editing. Copy/Paste options are also included for a number of items in the program (ground-boxes, texture areas, scenery objects).

Most editing is performed using the mouse. For example, scenery objects are moved around by clicking and dragging. Context menus (right button click) are provided in all editing modes for quick access to commonly used funtions (eg rotate texture map by 90°, insert new course segment).

Moving around the 3D world is done using the keyboard, primarily with the arrow keys. This occurs in real-time. You can move around using the same viewing position and keys as in MTM, thus giving a close approximation to how your track will appear in the game itself. A small map indicates your current position and viewing orientation at all times.

All editing functions can be performed in any viewing orientation, although some functions are easy to do in top-down (or near-top-down) viewing.

Editing is implemented in 5 modes, accessed via toolbar buttons. The modes are Terrain, Textures, Course, Objects and GroundBoxes.
