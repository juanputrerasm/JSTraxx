GroundBox Editing

GroundBox Editing.

Enter GroundBox Edit mode using the fifth button in the Editmode Toolbar.

The "ground-box" layer provides for solid cuboid structures that can be placed around the world terrain. Each box has 6 flat, textured faces and is aligned on terrain grid-squares - the altitude of the lower and upper face can be set freely, to create objects resting on the ground, below ground or "floating".

These are often used for bridges, overhanging rock structures, tunnels, large buildings etc, and are generally more efficient - but less flexible - than BIN models. Complex structures can be assembled by arranging ground-boxes on adjacent squares.

To insert a new box, right-click on the required grid square (which will be highlighted in red) and select Insert. The new box will have its top and bottom face located at the default altitudes, or at the altitudes of the last box you added/edited.

Raising and Lowering ground boxes.

You can do this two ways: using the keyboard or using the Top and Bottom values in the side-bar.

To use the keyboard, click to select the top face of a box (which will then be outlined in magenta) then use the S/X (or [ ]) keys just like when you're editing terrain. This will move the top face up and down. To do the same with the bottom level, select any face other than the top and use the keys as above.

To use the side-bar values, click to select any face on the box then you can set both the top and bottom positions for the box.

Note that whenever you click to select a box, the side-bar Top and Bottom values will display the current positions for that box.

Whenever you add a new box it will obtain its top and bottom locations from the values currently displayed in the side-bar. This means that when you add several boxes one after another they will be initially located at the same altitudes.

Tip: If you want to change a number of existing ground boxes to a particular top or bottom altitude, you can specify the position once then select and right-click the side-bar Top or Bottom value to Copy the number. Then click on the other ground-boxes ony by one and Paste the number back in each time.

Setting the face textures for ground boxes.

Newly inserted ground boxes by default adopt the currently selected texture on all faces (unless you copy/cut and paste - see below).

Just as in terrain texture editing, you can click to select a face than use the Apply button in the Textures Box.

There are also four "Paint" modes, which enable you to apply the currently selected texture to any face with a single click. In Paint Face mode, the texture is applied only to the face that you click on. The texture can be applied to several faces at once by using one of the Paint Sides, Paint Top/Bottom and Paint All Sides modes.

Copying ground boxes.

You can right-click a ground-box and select Copy Box or Cut Box from the popup menu. A copy of the box (ie with same top/bottom altitudes and texture mappings) can then be inserted using the Paste Box option when you right-click on an unused terrain square.

Tip: You can also use <Ctrl>+V to paste ground boxes - just run the mouse over the terrain squares, hitting <Ctrl>+V to insert multiple copies of a ground box (very useful for large structures like long bridges etc).

To delete a ground box, just right-click it and select Delete (or Cut Box). Or you can use the <Del> key after selecting the box.

You can't move ground boxes around.
